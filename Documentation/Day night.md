**To use it, simply check the Sun enable box.**

But be careful, because you need to have the light enabled for all of this to work; also, if the shadows aren't working, you can reset them using the "cast shadows" or "dynamic shadows" checkboxes in the light settings.

The other things are the settings for the lights and direction of the sun
