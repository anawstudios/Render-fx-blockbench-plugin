# Smooth surface

<img width="753" height="231" alt="image" src="https://github.com/user-attachments/assets/92185fe7-be39-4f3f-bb5b-aa46e5a73ca3" />

In this section, you can remove the old, **ugly lighting that affected the face surface by surface**, rather than being smooth like in real life.

But be careful there's a bug: if you model with this section enabled, you might end up with completely black faces. You should enable "backface culling" in the culling section; that should fix it.
